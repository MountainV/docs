## Schnellstart

```bash
git clone https://github.com/MountainV/docs.git
cd docs
```

Dann eine neue Doku anlegen:

1. Branch erstellen: `git checkout -b docs/mein-thema`
2. Markdown-Datei unter dem passenden Ordner anlegen.
3. Commit, Push, Pull Request öffnen.

## Prinzipien

> **Was nicht dokumentiert ist, existiert nicht.**

- Schreib so, dass es ein neues Teammitglied versteht.
- Lieber kurz und aktuell als lang und veraltet.
- Jede Änderung läuft über einen Pull Request.
