# Erste Schritte

Willkommen im MountainV-Team! Diese Seite bringt dich in wenigen Minuten
startklar.

## 1. Zugang

- GitHub-Account bei der Org [MountainV](https://github.com/MountainV) hinterlegt.
- Repos lokal klonen:

```bash
git clone https://github.com/MountainV/docs.git
```

## 2. Werkzeuge

| Zweck | Empfehlung |
|-------|-----------|
| Editor | VS Code |
| Git-Client | `git` CLI oder GitHub Desktop |
| Markdown-Vorschau | eingebaut in VS Code (`Strg`+`Shift`+`V`) |

## 3. Dein erster Beitrag

1. Such dir ein Issue mit dem Label `good first issue`.
2. Lies den [Git-Workflow](git-workflow.md).
3. Leg einen Branch an und öffne einen Pull Request.

## 4. Fragen?

Mach ein [Issue](https://github.com/MountainV/docs/issues/new/choose) auf
oder nutze die Diskussionen.
