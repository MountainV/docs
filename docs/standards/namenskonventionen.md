# Namenskonventionen

Einheitliche Namen machen das Repo leichter lesbar.

## Branches

| Präfix | Zweck |
|--------|-------|
| `docs/` | Dokumentation |
| `feat/` | neue Funktion/Inhalt |
| `fix/` | Fehlerbehebung |
| `chore/` | Aufräumen, Tooling |

Beispiel: `docs/git-workflow`

## Dateien & Ordner

- Kleinbuchstaben, Wörter mit Bindestrich: `erste-schritte.md`
- Keine Umlaute in Dateinamen (`ue`, `ae`, `oe` statt `ü`, `ä`, `ö`).
- Pro Thema eine Datei.

## Labels

Siehe die org-weiten Labels – Schema `kategorie: wert`,
z. B. `type: bug`, `status: triage`, `priority: high`.
