# Mitwirken

Danke, dass du zur MountainV-Doku beiträgst! So läuft's:

## Workflow

1. **Issue checken oder anlegen** – beschreibe, was du tun willst.
2. **Branch erstellen** nach dem Schema:
   - `docs/<thema>` – neue oder geänderte Doku
   - `fix/<thema>` – Korrekturen
   - `feat/<thema>` – neue Inhalte/Features
3. **Änderung machen** – ein Thema pro PR.
4. **Pull Request öffnen** – nutze die Vorlage und verlinke das Issue (`Closes #123`).
5. **Review abwarten** – mindestens eine Freigabe, dann Merge.

## Commit-Nachrichten

Kurz, im Imperativ, auf Deutsch:

```
Git-Workflow-Guide ergänzen
Tippfehler in Namenskonventionen korrigieren
```

## Stil

- Überschriften mit `#`, `##`, `###` sauber verschachteln.
- Codeblöcke mit Sprach-Angabe (```` ```bash ````).
- Zeilen nicht künstlich umbrechen – ein Satz, eine Zeile ist ok.
- Links relativ halten, wenn sie ins selbe Repo zeigen.
